I would like to the Agent running the agent tab to be able to control the Geany UI.
Ideally access to all features, but most important are.

- opening files in the editor
- scrolling to changed text
- closing files 
- saving unsaved editor files before starting work
- executing plugin menu items from the tool menu
- Executing menu bar buttons
- executing menu buttons and items from the treebrowser plugin
- refreshing UI with changes made by the agent.

It clearly should be possible for the agent to execute UI driven operations, and the system we build should allow scripted cli access as well to the same operations.
